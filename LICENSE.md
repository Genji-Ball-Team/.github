# License status

The Genji-Ball-Team shared files and config do **not** currently have an open-source license, the same as [Genji Ball: Community Edition](https://github.com/Genji-Ball-Team/GenjiBall-CE/blob/main/LICENSE.md). By default, that means the authors keep their rights.

## What you can do

- Read the code, learn from it, and link to it.
- Fork this repository on GitHub and open pull requests (GitHub's Terms of Service allow this for public repositories).

## What you should ask about first

- Copying significant parts of the code into another project.

If you want to, ask on the [Discord](https://discord.gg/sv9VVjh5pT).

## Contributions

By opening a pull request, you agree that your contribution may be included and distributed as part of these shared files, and that it can be placed under an open-source license later if the project adopts one.

## Future plans

We would like to move the Genji Ball projects to a proper open-source license once the original authors of the game mode agree.
