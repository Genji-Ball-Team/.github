# Contributing to Genji Ball

Thanks for helping. Every Genji-Ball-Team repo works the same way:

- **Style:** follow [STYLE.md](https://github.com/Genji-Ball-Team/.github/blob/main/STYLE.md).
- **The repo's own rules:** read its `AGENTS.md` (commands, checks, repo-specific rules).
- **Issues first:** look for an issue, or open one, before a big change.
- **One topic per PR**, branched from `main`, with the PR template filled in and the issue linked (`Fixes #12`). A change that spans repos is one PR per repo, linked to each other.
- **Checks:** `npm run check` passes before a PR is done.
- **Questions:** ask on the [Discord](https://discord.gg/sv9VVjh5pT).
